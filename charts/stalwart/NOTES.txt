Stalwart Mail Server deployed successfully!

To get started, you may want to:

1. Check the service status:
   kubectl get svc {{ .Release.Name }}-stalwart

2. Check the pod status:
   kubectl get pods -l app.kubernetes.io/name=stalwart

3. Access the mail server using the NodePort:
   kubectl get svc {{ .Release.Name }}-stalwart -o jsonpath='{.spec.ports[?(@.name=="http")].nodePort}'

The mail server is configured with the following ports:
- HTTP: 8080
- HTTPS: 443
- SMTP: 25
- Submission: 587
- SMTPS: 465
- IMAP: 143
- IMAPS: 993
- Sieve: 4190
